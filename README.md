# Slow-It-Down

A React web app to create slowed + reverb edits for your favorite songs

---

## Live Demo

[Slow-It-Down](https://slow-it-down.vercel.app/)

---

## Features

* Upload a song from your device
* Edit the song speed and reverb effect in real-time
* Download the new song edit as a WAV file
* ** NOTE: realtime effects do not work well on mobile, but download will include effects **

---

## Tech Stack

### Frontend

* React
* Vite
* React Modern Audio Player

### Deployment

* Vercel
---

## Getting Started

### 1. Clone the repo
```
git clone https://github.com/jdylantapp/slow-it-down.git
cd slow-it-down
```
---

### 2. Install dependencies

#### Frontend
```
cd frontend
npm install
```
---

### 3. Run locally

#### Frontend
```
npm run dev
```
